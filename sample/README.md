# Cove 示例页素材

引导里“试一试”打开的练习页。素材由 Kira 2026-10-03 提供（原件在 `~/Desktop/Assets`）。

- `index.html`：示例页，按浏览器语言显示英／简中／繁中／日／韩。先视频，后五张图片（紧凑网格：竖图占左侧两行，其余四张横图各占一格）。
- 图片 5 张（Kira 用 ChatGPT 生成）：`mountain-lake.jpg`、`terrace-portrait.jpg`、`lighthouse-night.jpg`、
  `villa-pool.jpg`、`coast-drive.jpg`。由 PNG 转成 JPEG（质量 82、渐进式、不带元数据），每张 2.2–2.7 MB 降到 190–340 KB。
- `caminandes-llamigos-excerpt.mp4`：18 秒，1280×720，H.264 + AAC，约 2.2 MB，已做 faststart。
  出自 Blender Foundation 的开放短片《Caminandes 3: Llamigos》，按 CC BY 3.0 许可，**必须署名**；
  署名写在页面底部，不要删。发布前请再核对一次 caminandes.com 上的许可说明。
- `poster.jpg`：视频第 6 秒的一帧，作封面。

发布：随 `docs/legal/` 一起传到 GitHub Pages 仓库（i9394/Viohold 的 `legal/sample/`），
地址为 `https://i9394.github.io/Viohold/legal/sample/`。上线后把 App 里引导的示例地址切到这里。
