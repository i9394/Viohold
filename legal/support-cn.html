Cove 技术支持

常见问题

广告过滤

页面上还是有广告，怎么办？

Cove 的过滤引擎覆盖大部分横幅、弹窗、悬浮条、跳转与跟踪器，但没有过滤器能做到 100%。先到 设置 → 广告过滤 → 更新广告规则 拉取最新规则；对顽固元素，点地址栏的盾牌图标，用 隐藏干扰元素 手动移除。若某个站点始终有广告，可通过上方邮箱把页面地址发给我们。

过滤后页面显示异常或按钮点不动。

偶尔过滤规则会误删页面需要的元素。到 设置 → 广告过滤 → 过滤规则，关掉对应规则（横幅 / 弹窗 / 悬浮 / 跳转拦截）后刷新页面；也可以把该站点加入 站点白名单，仅对它停用过滤。

如何开启 Safari 内容拦截器？

设置 → 广告过滤 → Safari 内容拦截，点 启用 跳转到 iOS 设置中打开 Cove 扩展。开启后广告规则与 Safari 共用。

隐私与应用锁

如何锁定 App？

设置 → 隐私与安全 → 设置密码。设好密码后可开启 Face ID 解锁。从后台回到 App 时需要验证。

切换 App 时内容会被看到吗？

Cove 进入后台时会自动遮挡内容，不会出现在 App 切换器中。

浏览数据存在哪里？

浏览历史、网站数据和已保存文件保存在本地。书签、首页快捷站点及符合条件的普通标签页可通过您的私有 Apple iCloud 数据库同步；诊断数据另按隐私政策处理。可在 浏览历史 页点 清除 删除本地历史。

文件与离线

保存的文件在哪里？

打开 文件 标签页，内容会自动按视频、图片、文档分类。

能导入其他 App 的文件吗？

可以。在任意 App 中使用 iOS 分享菜单，选择 Cove 即可导入。

为什么在某些网站不能保存资源？

为尊重版权，Cove 维护了一份覆盖主流内容平台的域名黑名单，这些页面不提供保存功能。详见用户协议。

可以同时下载几个视频？

免费版一次下载一个视频，其余已接受任务排队等待。Cove Pro 支持多个视频同时下载。实际速度受来源网站、网络及设备影响，Pro 不保证单个任务更快。

播放与转码

播放器支持哪些格式？

内置播放器支持常见视频/音频格式，包括 MP4、MOV、M4V。TS 文件会自动转为 MP4 以保证流畅播放。

「格式转换」是做什么的？

支持的保存任务所需的自动兼容转换无需 Pro。Cove Pro 另提供 HEVC (H.265) 输出；实际体积和播放兼容性取决于源文件及播放设备。

如何使用手势播放器？

在 设置 → 播放设置 → 手势播放器 开启。提供亮度 / 音量 / 进度滑动手势、长按倍速与记忆播放位置。手势播放器为 Cove Pro 功能。

Cove Pro 与订阅

新设备上如何恢复 Pro？

打开 App → 设置 → Cove Pro → 恢复购买，确保使用购买时的同一 Apple ID 登录。

如何取消订阅？

iOS 设置 → [你的名字] → 订阅 → Cove Pro → 取消订阅。取消后 Pro 功能持续到当前计费周期结束。

会自动扣费吗？

会。除非在当前周期结束前至少 24 小时取消，订阅将自动续期。可随时在 App Store 账户设置中管理或取消。
